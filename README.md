# auth-app-practice

## 概要

COACHTECH 教材 Tutorial 10-1「認証機能 ハンズオン演習」で作成した成果物です。学習の一環で作成しました。ユーザー登録とログイン機能のみのサイトです。

## 使用技術

- PHP 8.5.12
- Laravel 13.40.0
- Laravel Fortify（認証）
- MySQL

## 学んだこと

- Laravel Fortifyの実装方法
- ログインを確認してからダッシュボードを表示するよう誘導する仕組み

## 動作確認

ブラウザから、

- <http://localhost/login>
- <http://localhost/register>
- <http://localhost/dashboard>
  にアクセスして確認しました。
